## 修复"归档确认后无记录产生"Bug

**问题根因分析（3 个叠加问题）：**
1. `handleArchiveConfirm` 中 `invoke('archive_file')` 失败时只 `console.warn`，用户看不到错误提示（如 vault_path 未配置导致后端返回错误）
2. 归档成功后只关闭弹窗，不触发 ArchiveTimelineView 重新加载数据（组件只在 mount 时加载一次）
3. localStorage `archive_configured` 标记可能与后端 DB 中的 `vault_path` 不同步

**修复内容（`src/App.jsx`）：**
- 新增 `archiveRefreshKey` state，归档成功后 +1 驱动时间线组件卸载重挂载
- `handleArchiveConfirm`：成功后自动导航到 `archive_timeline` + 刷新；失败时 alert 提示用户，vault_path 未配置时引导打开设置
- `handleQuickArchive` / `handleArchiveFromCluster`：改为 async，打开弹窗前二次检查后端 `get_archive_config` 是否有 vaultPath
- `<ArchiveTimelineView key={archiveRefreshKey} />` 使用 key 驱动刷新
