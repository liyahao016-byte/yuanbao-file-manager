## 测试用例

### TC-1：首次归档 — SetupGuide 引导流程

**前提**：localStorage 中没有 `archive_configured` 标记

1. 点击侧边栏「快速归档」按钮
2. **预期**：弹出 ArchiveSetupGuide 三步引导弹窗
3. Step 1：点击「选择文件夹」
4. **预期**：弹出系统原生目录选择器（不是 mock 的 setTimeout）
5. 选择一个目录（如 `~/Documents/my-archive`）
6. **预期**：显示已选择的路径，「下一步」按钮变为可点击
7. 点击「下一步」进入 Step 2
8. **预期**：自动检测该目录下是否有 `.obsidian/` 文件夹
9. 如果未检测到：显示「未检测到 Obsidian」，开关默认关闭
10. 如果检测到：显示「检测到 Obsidian」，开关默认开启
11. 点击「下一步」进入 Step 3
12. **预期**：确认摘要页显示路径和 Obsidian 模式状态
13. 点击「完成配置」
14. **预期**：
    - localStorage 写入 `archive_configured=true`
    - 后端 SQLite `archive_config` 表写入 vault_path 和 obsidian_mode
    - 归档目录下自动创建 PARA 五目录（00-inbox, 10-projects, 20-areas, 30-daily, 90-archive）

### TC-2：从簇卡片归档

**前提**：已完成 TC-1，归档已配置

1. 进入「智能文件夹」视图
2. 找到任意一个有文件的簇卡片
3. 点击卡片上的「归档本簇」按钮（文档图标）
4. **预期**：弹出 ArchiveFromClusterModal，预填簇名称和文件列表
5. AI 预填会在 2 秒后自动填入标题和产出（当前是 mock）
6. 修改标题、选择优先级、输入产出描述
7. 添加自定义标签（输入后按回车或逗号）
8. 点击「确认归档」
9. **预期**：
    - 控制台打印 `[Archive] 归档成功:`
    - 归档目录下 `30-daily/2026/08/2026-08-31.md` 文件被创建/追加
    - 文件内容包含 `### ✅ HH:MM 标题` 格式的归档段落
    - SQLite `archives` 表新增一条记录
    - SQLite `archive_files` 表新增关联文件记录

### TC-3：快速归档

**前提**：已完成 TC-1

1. 点击侧边栏「快速归档」按钮
2. **预期**：弹出 QuickArchiveModal（橙色主题）
3. 手动输入标题、项目、优先级等信息
4. 可选：勾选「关联文件」展开文件选择
5. 点击「确认归档」
6. **预期**：同 TC-2 的归档写入验证

### TC-4：归档时间线查看

**前提**：已完成 TC-2 或 TC-3（至少有一条归档记录）

1. 点击侧边栏「归档时间线」导航
2. **预期**：
    - 顶部统计卡片显示本周/本月归档数据
    - 时间线按日期分组展示归档卡片
    - 如果没有真实数据，显示 mock 降级数据（3 条）
    - 有真实数据时，显示真实归档记录
3. 点击某张卡片
4. **预期**：展开显示详情（卡点、下一步、关联文件）
5. 使用搜索框搜索关键词
6. **预期**：卡片实时过滤
7. 点击标签 chip
8. **预期**：按标签筛选

### TC-5：新场景簇验证

1. 确认工作区中有 `.md` 文件
2. 进入「智能文件夹」视图
3. **预期**：看到新增的「知识归档」和「工作日志」两个场景簇（如果有匹配文件）

### TC-6：浏览器降级验证

1. 关闭 Tauri 桌面应用
2. 在浏览器中打开 `http://localhost:5173`
3. 点击「快速归档」
4. **预期**：SetupGuide 使用 mock 目录选择（800ms 延迟后自动填入路径）
5. 完成配置后归档
6. **预期**：归档操作 catch 到错误并 console.warn，不阻塞 UI

## 已修复的联调问题

| # | 问题 | 修复 |
|---|------|------|
| 1 | `archive.output.toLowerCase()` 空指针 | 改为 `(archive.output \|\| '').toLowerCase()` |
| 2 | `archive.tags.some()` 空指针 | 改为 `(archive.tags \|\| [])` |
| 3 | `archive.tags.map()` 空指针 | 改为 `(archive.tags \|\| []).map()` |
| 4 | `useMemo` 缺少 `archives` 依赖 | 添加到依赖数组 |
| 5 | 空状态用 `MOCK_ARCHIVES.length` 判断 | 改为 `archives.length` + `loading` 检查 |
| 6 | `handleSelectDir` 是 mock setTimeout | 改为 Tauri `open({ directory: true })` |
| 7 | Obsidian 检测是 random mock | 改为 `invoke('detect_obsidian_vault')` |
| 8 | top-level await import 不兼容 | 改为静态 import + try/catch |
| 9 | `query_archives` 参数未显式传递 | 改为传全部 6 个 null 参数 |
| 10 | `detect_obsidian_vault` 命令未注册 | 新增 Tauri 命令 + invoke_handler 注册 |
