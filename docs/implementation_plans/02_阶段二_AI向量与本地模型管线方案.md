## 阶段二实施细节：Rust 下的 AI 管线设计

由于我们抛弃了 Python，完全走 Rust 极客路线，这对性能是极大的提升，但我们需要引入以下底层库来实现“文件管理AI”文档中的诉求：

### 1. 向量模型推理框架 (运行 BGE-M3)
- **方案选择**：我们将引入 **`ort` (ONNX Runtime for Rust)**。
- **流程**：由于最终决策为**模型打包内置**，我们将在 Tauri 构建时把 `bge-small-zh-v1.5.onnx` 模型放入 `assets` 资源目录。后端启动时直接从本地资源包加载，并在纯 CPU 或 Apple Silicon (CoreML) 下计算出一个 `384` 维的特征向量（Embedding）。

### 2. 向量数据库 (存储 Embedding)
- **方案选择**：**`sqlite-vec`**。
- **流程**：作为一个以纯 C 编写的 SQLite 插件，极其轻量。将其动态链接到 `rusqlite` 中，建表并进行向量余弦相似度匹配计算。

### 3. HDBSCAN 聚类算法 (生成动态分类标签)
- **方案选择**：由于 Rust 生态中原生高效的 HDBSCAN 实现较少，我们将探索 Rust ML 生态（如 `linfa`）中的相关密度聚类算法（DBSCAN/OPTICS），以实现本地文件分类。
