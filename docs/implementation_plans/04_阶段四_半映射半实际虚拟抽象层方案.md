# 阶段四实施方案：「半映射半实际」虚拟数据抽象层与代码屏蔽

## 1. 架构目标
- **半映射 (Virtual Layer)**：AI 重命名/分类打标默认只修改 SQLite 数据库里的 `virtual_name` 和元数据，保护 Mac 实体磁盘原文件及第三方软件依赖不破坏。
- **半实际 (Physical Layer)**：预览抽屉中清晰对比“虚拟显示名”与“磁盘真实路径”，并提供独立的 `sync_virtual_name_to_disk` 允许用户一键同步更名到 Mac 实体磁盘。
- **代码文件屏蔽**：在扫描和搜索算法中全量过滤 `.js`, `.py`, `.rs`, `.json`, `node_modules` 等开发工程文件。
