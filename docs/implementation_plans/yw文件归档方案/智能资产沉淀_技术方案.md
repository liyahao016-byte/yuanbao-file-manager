#### 命令 4: `scan_asset_task`（核心扫描命令）

```rust
#[tauri::command]
pub async fn scan_asset_task(
    task_id: String,
    state: State<'_, AppState>,
) -> Result<AssetStats, String>
```

**逻辑**（分 4 个 Phase）：

```
Phase 1 — 准备
  1. 从 DB 读取 task 配置
  2. 更新 task.status = "scanning"
  3. 读取已有 asset_items 的 content_hash 集合 (用于增量跳过)
  4. 用 walkdir 遍历 workspace_path (max_depth = 10)

Phase 2 — 规则扫描 (同步, 快速)
  对每个文件:
    a. 硬性排除检查:
       - 是否在 exclude_dirs 中? → NOISE
       - 文件名匹配 exclude_patterns? → NOISE
       - 是否隐藏文件 (以 . 开头)? → NOISE
    b. 属性筛选:
       - include_types 非空 && 扩展名不在白名单? → NOISE
       - file_size 不满足 filters 中的条件? → NOISE
       - file_mtime 不满足条件? → NOISE
    c. 增量跳过:
       - 计算 SHA256 hash (仅对 < 10MB 的文件)
       - 若 hash 在已有集合中 → 跳过 (保持原分类)
    d. 文件名标签匹配:
       - 对 policy.tags 逐个检查文件名是否包含标签关键词(去#号)
       - 命中任一 → 候选 ASSET (confidence: 0.85, match_rule: "文件名含{tag}")
    e. 未命中标签 → 进入 AI 候选列表

Phase 3 — AI 摘要 + 内容标签匹配 (异步, 逐文件)
  对 AI 候选列表中的每个文件:
    a. 调用 file_parser::read_text_snippet(path, 2000) 读取前 2000 字
    b. 若读取失败或内容为空 → PENDING (confidence: 0.50)
    c. 调用 ollama::generate_summary(file_name, file_type, snippet) 生成摘要
    d. 在 AI 摘要文本中匹配 policy.tags 关键词
       - 命中 → ASSET (confidence: 0.75, match_rule: "AI摘要含{tag}")
       - 未命中 → PENDING (confidence: 0.50)
    e. AI 调用失败/超时(30秒) → PENDING, ai_summary = null

Phase 4 — 写入结果
  1. 批量 UPSERT asset_items (用 INSERT OR REPLACE)
  2. 统计 counts → 更新 asset_tasks 的统计缓存
  3. 更新 task.status = "completed", last_scan_at = now
  4. 返回 AssetStats
```

**增量扫描策略详细说明**：

```rust
// 增量扫描决策树
fn should_skip_file(file_path: &Path, existing_items: &HashMap<String, (String, i64)>) -> bool {
    // existing_items: file_path -> (content_hash, file_mtime)
    if let Some((old_hash, old_mtime)) = existing_items.get(file_path.to_str().unwrap()) {
        let metadata = fs::metadata(file_path).ok();
        if let Some(meta) = metadata {
            let current_mtime = meta.modified()
                .ok()
                .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
                .map(|d| d.as_secs() as i64)
                .unwrap_or(0);
            // 如果 mtime 没变, 直接跳过 (不需要重新算 hash)
            if current_mtime == *old_mtime {
                return true;
            }
        }
    }
    false
}
```

```rust
#[tauri::command]
pub async fn generate_knowledge_base(
    task_id: String,
    kb_name: Option<String>,             // 知识库名称 (默认: {workspace}_知识库_{日期})
    output_dir: Option<String>,          // 输出目录 (默认: workspace 根目录)

```

  如果 selected_item_ids 非空 → 按 ID 查询指定条目
  否则 → SELECT * FROM asset_items WHERE task_id = ? AND classification = 'ASSET'

Step 2 — 逐文件读取完整内容 + 生成详细摘要
  对每个 ASSET 文件:
    a. 调用 file_parser::read_text_snippet(path, 5000) 读取前 5000 字 (比扫描时更多)
    b. 调用 ollama 生成更详细的内容提取:

        要求：
        1. 提取关键结论、决策、数据

        3. 标注关键信息（加粗）
        4. 不超过 500 字

        内容：{snippet}"
    c. 若 AI 失败 → 使用扫描时的 ai_summary 兜底

Step 3 — 按分组方式组织章节
  group_by = "tag":
    - 按 tags 分组, 无标签的归入"其他"
    - 同一文件有多个标签时, 归入第一个标签的章节
  group_by = "type":
    - 按 file_type 分组: 文档类 / 表格类 / 代码类 / 图片类 / 其他
  group_by = "dir":
    - 按一级子目录分组

Step 4 — 拼装 Markdown
  模板结构:
  ```
  # {kb_name}
  > 自动生成于 {date} | 基于 {N} 份资产文件 | 由智能资产沉淀生成

  ## 目录
  {auto_generated_toc}

  ---

  ## 一、{chapter_title}

  ### 1.1 {file_title}
  > 📄 来源：{file_ref} | {file_size} | {file_date}
  > 🏷️ 标签：{tags}

  {ai_extracted_content}

  ---
  ... (更多章节)

  ## 附录：资产清单
  | # | 文件名 | 类型 | 大小 | 标签 | 匹配方式 |
  {table_rows}

  ---
  *本文档由智能资产沉淀自动生成*
  ```

  如果 obsidian_mode = true:
    - 文件来源用 [[wikilink]] 格式: `[[PRD_v3_final]]`
    - 标签用 Obsidian 原生格式: `#终稿 #PRD`
    - 添加 YAML frontmatter:
      ```yaml
      ---
      title: {kb_name}
      date: {date}
      tags: [知识库, 自动生成]
      sources: {asset_count}
      ---
      ```

Step 5 — 写入文件 + 记录历史
  1. 写入 .md 文件到 output_dir
  2. INSERT INTO asset_kb_history
  3. 返回 KnowledgeBaseResult {output_path, asset_count, file_size}
```

/// 为文件生成 3-5 句话的简短摘要 (用于扫描阶段)
pub async fn generate_file_summary(
    file_name: &str,
    file_type: &str,
    content_snippet: &str,
) -> Result<String, String> {
    let prompt = format!(
        r#"你是一个文件内容分析专家。请阅读以下文件内容片段，生成一段 3-5 句话的摘要。
要求：
1. 提取文件的核心主题和关键信息
2. 如果是方案/报告类，提取关键结论
3. 如果是代码类，描述模块功能
4. 摘要必须简洁专业，不超过 200 字
5. 只输出摘要内容，不要任何前缀说明

文件名：{}
文件类型：{}
内容片段：
{}"#,
        file_name, file_type, content_snippet
    );

    // 复用现有的 ollama 调用逻辑
    let client = reqwest::Client::new();
    let req = serde_json::json!({
        "model": "qwen2.5:32b",
        "prompt": prompt,
        "stream": false
    });

    let res = client
        .post("http://localhost:11434/api/generate")
        .json(&req)
        .timeout(std::time::Duration::from_secs(30))
        .send()
        .await
        .map_err(|e| format!("Ollama 摘要生成失败: {}", e))?;

    let body: serde_json::Value = res.json().await
        .map_err(|e| format!("解析响应失败: {}", e))?;

    Ok(body["response"].as_str().unwrap_or("").trim().to_string())
}
```

2. 保留重要的列表和要点

5. 直接输出 Markdown 内容，不要前缀说明

        file_name, file_type, content_snippet

## 五、规则引擎详细实现

### 5.1 核心分类函数

```rust
/// 文件分类结果
struct ClassifyResult {
    classification: String,  // ASSET / NOISE / PENDING
    confidence: f64,
    match_rule: String,
    tags: Vec<String>,
}

/// 4 阶段规则引擎
fn classify_by_rules(
    file_path: &Path,
    file_name: &str,
    file_size: i64,
    file_mtime: i64,
    policy: &AssetPolicy,
) -> ClassifyResult {
    // Phase 1: 硬性排除 — 目录
    for dir in &policy.exclude_dirs {
        if file_path.to_str().unwrap_or("").contains(dir) {
            return ClassifyResult {
                classification: "NOISE".into(),
                confidence: 1.0,
                match_rule: format!("排除目录: {}", dir),
                tags: vec![],
            };
        }
    }

    // Phase 1: 硬性排除 — 文件名模式
    let lower_name = file_name.to_lowercase();
    for pattern in &policy.exclude_patterns {
        if matches_glob_pattern(&lower_name, pattern) {
            return ClassifyResult {
                classification: "NOISE".into(),
                confidence: 1.0,
                match_rule: format!("排除模式: {}", pattern),
                tags: vec![],
            };
        }
    }

    // Phase 1: 隐藏文件
    if file_name.starts_with('.') {
        return ClassifyResult {
            classification: "NOISE".into(),
            confidence: 1.0,
            match_rule: "隐藏文件".into(),
            tags: vec![],
        };
    }

    // Phase 2: 属性筛选 — 类型白名单
    let ext = file_path.extension()
        .and_then(|s| s.to_str())
        .map(|s| format!(".{}", s.to_lowercase()))
        .unwrap_or_default();

    if !policy.include_types.is_empty() {
        let in_whitelist = policy.include_types.iter()
            .any(|t| t.to_lowercase() == ext);
        if !in_whitelist {
            return ClassifyResult {
                classification: "NOISE".into(),
                confidence: 0.95,
                match_rule: format!("不在类型白名单: {}", ext),
                tags: vec![],
            };
        }
    }

    // Phase 2: 属性筛选 — 自定义 filters
    for filter in &policy.filters {
        if !pass_filter(filter, file_size, file_mtime, file_name, &ext) {
            return ClassifyResult {
                classification: "NOISE".into(),
                confidence: 0.90,
                match_rule: format!("属性不满足: {}.{}.{}", filter.field, filter.op, filter.value),
                tags: vec![],
            };
        }
    }

    // Phase 3: 文件名标签匹配
    let mut matched_tags = Vec::new();
    for tag in &policy.tags {
        let keyword = tag.trim_start_matches('#').to_lowercase();
        if lower_name.contains(&keyword) {
            matched_tags.push(tag.clone());
        }
    }

    if !matched_tags.is_empty() {
        return ClassifyResult {
            classification: "ASSET".into(),
            confidence: 0.85,
            match_rule: format!("文件名含标签: {}", matched_tags.join(", ")),
            tags: matched_tags,
        };
    }

    // Phase 3 未命中 → 返回 PENDING, 等待 Phase 4 (AI)
    ClassifyResult {
        classification: "PENDING".into(),  // 将由 AI 阶段重新判定
        confidence: 0.50,
        match_rule: "待 AI 分析".into(),
        tags: vec![],
    }
}
```

### 5.2 Glob 模式匹配

```rust
/// 简单的 glob 模式匹配 (支持 * 和 ?)
fn matches_glob_pattern(name: &str, pattern: &str) -> bool {
    let pattern = pattern.to_lowercase();
    let pattern = pattern.trim();

    if pattern.starts_with('*') && pattern.ends_with('*') {
        // *xxx* → contains
        let inner = &pattern[1..pattern.len()-1];
        name.contains(inner)
    } else if pattern.starts_with('*') {
        // *xxx → ends_with
        name.ends_with(&pattern[1..])
    } else if pattern.ends_with('*') {
        // xxx* → starts_with
        name.starts_with(&pattern[..pattern.len()-1])
    } else {
        // exact match
        name == pattern
    }
}
```

### 5.3 属性筛选器

```rust
fn pass_filter(
    filter: &AssetFilter,
    file_size: i64,
    file_mtime: i64,
    file_name: &str,
    ext: &str,
) -> bool {
    match filter.field.as_str() {
        "file_size" => {
            let threshold: i64 = filter.value.parse().unwrap_or(0);
            match filter.op.as_str() {
                "gt" => file_size > threshold,
                "lt" => file_size < threshold,
                _ => true,
            }
        }
        "file_mtime" => {
            // value = 天数 (如 "30" 表示最近30天)
            let days: i64 = filter.value.parse().unwrap_or(0);
            if days <= 0 { return true; }
            let cutoff = chrono::Local::now().timestamp() - (days * 86400);
            match filter.op.as_str() {
                "gt" => file_mtime > cutoff,  // 最近 N 天内
                "lt" => file_mtime < cutoff,  // N 天之前
                _ => true,
            }
        }
        "file_type" => {
            let types: Vec<&str> = filter.value.split(',').map(|s| s.trim()).collect();
            match filter.op.as_str() {
                "include" => types.iter().any(|t| ext == *t || ext == format!(".{}", t)),
                "exclude" => !types.iter().any(|t| ext == *t || ext == format!(".{}", t)),
                _ => true,
            }
        }
        "file_name" => {
            let lower_name = file_name.to_lowercase();
            let lower_value = filter.value.to_lowercase();
            match filter.op.as_str() {
                "contains" => lower_name.contains(&lower_value),
                "not_contains" => !lower_name.contains(&lower_value),
                _ => true,
            }
        }
        _ => true,
    }
}
```

### 5.4 SHA256 Hash 计算

```rust
fn compute_file_hash(path: &Path) -> Option<String> {
    // 只对 < 10MB 的文件计算 hash
    let metadata = fs::metadata(path).ok()?;
    if metadata.len() > 10 * 1024 * 1024 {
        return None;
    }

    let mut file = fs::File::open(path).ok()?;
    let mut hasher = Sha256::new();
    let mut buffer = [0u8; 8192];
    loop {
        let bytes_read = file.read(&mut buffer).ok()?;
        if bytes_read == 0 { break; }
        hasher.update(&buffer[..bytes_read]);
    }
    Some(format!("{:x}", hasher.finalize()))
}
```

```toml

```
